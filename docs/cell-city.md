# Cell City — 몸속 주식회사 (v0.90.0)

`#city`의 도트 마을을 한 건물 안의 회사로 바꿨다. 기존 탑다운 시점과 작은 캐릭터를 유지하고 지붕을 걷어낸 실내, 부서별 방과 작업 설비, 중앙 컨베이어를 표시한다. `#city3d`는 독립된 기존 시뮬레이션을 유지한다.

## 배치와 직원

48×34타일, 하나의 외벽 안에 7개 부서와 휴게실·물류 홀이 있다.

- 위쪽: 폐 산소 공급부, 뇌 신호 관제부, 장 영양 가공부.
- 양옆: 심장 순환 동력부, 골수 조직 수선부.
- 아래쪽: 간 물자 정리부, 직원 휴게실, 신장 노폐물 여과부.
- 가운데: 물류 배차 데스크, 한 바퀴 도는 컨베이어, 부서별 짧은 분기.

루비(적혈구)는 배차와 출고 부서를 오가고, 두두(심근세포)·솔솔(폐포세포)·반짝(신경세포)·보리(장세포)·맑음(신장세포)·모모(대식세포)·토리(섬유아세포)가 각 부서에서 일하다 휴게실을 다녀온다. 역할군당 한 명, 직원 8명과 별도 플레이어 1명이다. 인체 역할을 단순화한 생활 시뮬이며 의학적 대사 수치를 재현하지 않는다.

## 실제 물류

산소 공급부의 파란 산소통과 영양 가공부의 노란 식량 상자가 짧은 출고 벨트를 거쳐 중앙 순환 벨트에 오른다. 관제·동력·수선 부서가 실제 입고한 산소와 식량을 하나씩 소비해 작업하고, 그때 생긴 회수 상자를 정리부로 보낸다. 정리된 상자는 여과부에 도착해 배출된다.

설비 가동에는 담당 직원이 작업점 근처에 있어야 한다. 순환 펌프와 배차 근무는 벨트 속도에 영향을 준다. 벨트는 최소 속도를 유지해 물자가 고갈돼도 멈춰 갇히지 않는다. 물자는 최대 60개이며 재고와 운송량을 포함한 총량을 보존한다. 바닥의 장식 입자로 물류를 대신하지 않는다.

부서마다 재고·작업 진행·입고등·설비 움직임을 보여주고, 화면 구석에는 운송 중 산소·식량·회수품 개수만 짧게 표시한다.

## 조작

- 처음에는 자동으로 움직이는 회사 구경. 드래그·휠·±로 둘러보고 전체 보기로 한 층을 맞춘다. 모바일 첫 화면은 중앙 물류 홀을 크게 보여준다.
- 직원이나 직원 목록을 누르면 따라보기. ×로 해제한다.
- 출근하기에서 이름·옷·머리·피부를 정한 캐릭터를 만든다. WASD / 방향키 / 바닥 클릭 / 터치 방향패드로 이동한다.
- 벽·설비·벨트는 통과하지 못한다. 문과 벨트 위 보행 다리로 드나든다. 방의 빈 바닥 클릭은 이동, 설비 클릭은 다가가 작업 지원이다.
- 가까운 직원에게 인사하고 설비를 도울 수 있다. 지원은 해당 부서의 실제 작업을 15초 가속하며, 펌프 지원은 벨트도 빨라진다.
- 재생/정지, 1×/2×, 자동/낮/밤을 유지한다. 캐릭터 편집 중에는 진행을 멈추며 비활성 탭에서는 루프를 정지한다.

## 구조와 저장

`cell-office-layout.mjs`가 방·문·설비·벨트·다리 좌표와 충돌을 정의하고 `cell-office-logistics.mjs`가 생산·이동·입고·작업·배출을 처리한다. 기존 `cell-village-*` 모듈이 캐릭터·카메라·UI를 담당한다.

저장 키는 `pathopedia:cell-village:v1`, 내용 형식은 version 2다. 이전 캐릭터 이름·외형·시간·도움 횟수를 보존하면서 새 물류 홀로 옮긴다. 작업·정리·여과 누계를 추가 저장한다. 순간 재고와 운송 상태는 재입장 시 안정적인 초기 상태로 시작한다. 기존 3D 기록은 변경하지 않는다.

30fps, 메모리 배경 캔버스 한 장, 최대 DPR 2와 기존 Kontra.js(MIT)를 사용한다. 기존 Kenney Tiny Town(CC0) PNG 1개·5,042바이트를 실내 화분과 외부 지면에 재사용한다. 새 이미지·패키지·임시 파일은 없다. [에셋 활용 문서](cell-city-assets.md)를 함께 갱신한다.

검증 범위는 모든 부서·휴게실 도달, 문·벨트·설비 충돌, 8명 동선, 저장 이전, 물자 총량 보존, 전체 생산·분류·여과 흐름, 직원 부재와 플레이어 지원, 오프라인 캐시다. Work 설정에서 로컬 브라우저 사용이 꺼져 있어 실제 화면·계산된 스타일 검증은 미수행이다.
