# Cell City — 몸속 주식회사 (v0.92.0)

`#city`의 도트 마을을 한 건물 안의 회사로 바꿨다. 기존 탑다운 시점과 작은 캐릭터를 유지하고 지붕을 걷어낸 실내, 부서별 방과 작업 설비, 중앙 컨베이어를 표시한다. `#city3d`는 독립된 기존 시뮬레이션을 유지한다.

## 배치와 직원

48×34타일, 하나의 외벽 안에 7개 부서와 휴게실·물류 홀이 있다.

- 위쪽: 폐 산소 공급부, 뇌 신호 관제부, 장 영양 가공부.
- 양옆: 심장 순환 동력부, 골수 조직 수선부.
- 아래쪽: 간 물자 정리부, 직원 휴게실, 신장 노폐물 여과부.
- 가운데: 물류 배차 데스크, 한 바퀴 도는 컨베이어, 부서별 짧은 분기.

루비(적혈구)는 배차와 출고 부서를 오가고, 두두(심근세포)·솔솔(폐포세포)·반짝(신경세포)·보리(장세포)·맑음(신장세포)·모모(대식세포)·토리(섬유아세포)가 각 부서에서 일하다 휴게실을 다녀온다. 역할군당 한 명, 직원 8명과 별도 플레이어 1명이다. 인체 역할을 단순화한 생활 시뮬이며 의학적 대사 수치를 재현하지 않는다.

## 실제 물류

산소 공급부에서 충전한 파란 산소통과 영양 가공부에서 포장한 노란 상자를 직원이 직접 들어 출고대에 싣는다. 물자는 중앙 컨베이어를 지나 도착 부서의 입고대에 쌓인다. 담당 직원이 산소·식량을 하나씩 받아 작업대까지 운반해야 설비 재고가 된다.

관제·동력·수선 부서는 산소와 식량을 하나씩 소비해 작업하고 회수 상자를 만든다. 직원이 다시 출고대까지 옮겨 정리부로 보낸다. 정리부 직원은 입고 상자를 분류한 뒤 여과부로 보내고, 여과부 직원이 받아 수조에 투입하면 배출로 끝난다. 직원 손의 물자 색과 형태는 벨트 위 물자와 같다. 완성품은 작업대에서 잠시 출고 준비를 마친 뒤 운반한다.

설비 가동에는 담당 직원이 작업점에 있어야 한다. 작업·운반을 마친 직원은 휴게실에 다녀온다. 인사를 받아도 들고 있던 상자와 이동 경로를 보존하고 잠깐 멈췄다가 이어간다. 순환 펌프와 배차 근무는 벨트 속도에 영향을 주며, 벨트는 최소 속도를 유지한다. 벨트 물자는 최대 60개, 입고대는 종류별 산소·식량 6개 또는 회수품 16개, 작업대 완성품은 1개까지 기다린다. 입고대·손·작업대·벨트·소비·여과를 합쳐 총량을 보존한다.

산소 탱크는 현재 충전 진행에 따라 차오르고 출고할 때 비워진다. 포장대에는 공정에 따라 식량이 놓이고 완성 상자가 대기한다. 관제 모니터와 펌프·수선 동작은 실제 가동 상태를 따른다. 여과 수조는 투입량·처리 진행·배출에 맞춰 변한다. 입고대 상자와 입고·출고등도 실제 인수인계를 표시한다. 화면 구석의 운송량에는 벨트와 직원 손의 물자를 함께 센다.

## 회사의 하루와 작은 사건

아침 점검 → 오전 업무 → 교대 점심 → 오후 업무 → 마감 정리 → 야간 근무가 시계와 연결된다. 점검과 정리는 각 직원이 하루 한 번 작업점에서 수행한다. 두 명씩 휴식 자리를 예약하고 들고 있는 상자와 진행 중 작업을 마친 뒤 이동한다. 점심은 먼저 비울 수 있는 짝부터 교대로 다녀오며 나머지 부서는 계속 움직인다.

동료와 마주치면 서로 바라보고 짧은 말풍선으로 인사한다. 휴게실에서는 마주 앉아 대화·커피·독서·식사를 하고, 직원에 따라 기지개를 켜거나 화분에 물을 준다. 긴 대사나 별도 관계 관리 화면을 추가하지 않는다.

가끔 영양 가공부에 포장 지원이 필요하면 루비가 실제로 이동해 함께 작업한다. 운반 중 떨어뜨린 상자는 바닥에 남고 루비가 주워 원래 목적지에 전달한다. 플레이어가 먼저 주워도 같은 상자 한 개의 소유권만 이전한다. 직원이 회수와 배송을 마치므로 플레이어 없이도 진행된다. 사건 버튼은 해당 위치를 보여주며 산책 중에는 다가가 돕는다.

물류 홀 오른쪽에 플레이어 책상과 사물함을 둔다. 책상에서 앉기, 사물함에서 화분·책과 메모·작은 수조 세 가지 소품 구성을 바꾸기, 휴게실에서 커피와 휴식을 할 수 있다. 직원의 좌석 2개와 플레이어 휴식 위치는 따로 둬 자리를 겹쳐 예약하지 않는다.

## 조작

- 처음에는 자동으로 움직이는 회사 구경. 드래그·휠·±로 둘러보고 전체 보기로 한 층을 맞춘다. 모바일 첫 화면은 중앙 물류 홀을 크게 보여준다.
- 직원이나 직원 목록을 누르면 따라보기. ×로 해제한다.
- 출근하기에서 이름·옷·머리·피부를 정한 캐릭터를 만든다. WASD / 방향키 / 바닥 클릭 / 터치 방향패드로 이동한다.
- 벽·설비·벨트는 통과하지 못한다. 문과 벨트 위 보행 다리로 드나든다. 방의 빈 바닥 클릭은 이동, 설비 클릭은 다가가 작업 지원이다.
- 가까운 직원에게 인사하고 설비를 도울 수 있다. 지원은 해당 부서의 실제 작업을 15초 가속하며, 펌프 지원은 벨트도 빨라진다. 직원이 자리를 비웠을 때 완성된 상자는 작업대에서 담당자를 기다린다.
- 완성품이 놓인 작업대에서 상자를 하나 받아 직접 배달할 수 있다. 손에 든 상자의 목적지를 표시하고 배송 버튼을 누르면 이동해 전달한다. 떨어진 상자도 같은 방식으로 회수한다. 빈 입고 공간이 생길 때까지 물자를 손에 보존한다.
- **내 자리**로 책상에 이동하고, 사물함·소파·커피 설비를 클릭하거나 가까이서 E로 사용한다. 이동하거나 일어나기를 누르면 휴식을 끝낸다. 행동 버튼은 현재 가능한 행동만 짧게 표시한다.
- 재생/정지, 1×/2×, 자동/낮/밤을 유지한다. 캐릭터 편집 중에는 진행을 멈추며 비활성 탭에서는 루프를 정지한다.

## 구조와 저장

`cell-office-layout.mjs`가 방·문·설비·벨트·다리와 인수인계·휴식·개인 자리 좌표를 정의한다. `cell-office-logistics.mjs`가 생산·벨트 이동·입고대·작업 재고·완성품·배출을 처리한다. `cell-office-life.mjs`가 하루 일정·교대·대화·사건·수작업 배달을 관리하고, `cell-village-world.mjs`가 실제 이동과 조작을 연결한다. 기존 렌더러·UI·카메라 진입점을 유지한다.

저장 키는 `pathopedia:cell-village:v1`, 내용 형식은 version 2다. 캐릭터 이름·외형·시간·도움 횟수·작업·정리·여과 누계에 개인 자리 소품과 직접 배달 누계를 더한다. 이전 version 2 저장도 읽는다. 순간 재고·손의 상자·운송 상태·현재 사건과 휴식은 재입장 시 초기 상태로 시작한다. 기존 3D 기록은 변경하지 않는다.

30fps, 메모리 배경 캔버스 한 장, 최대 DPR 2와 기존 Kontra.js(MIT)를 사용한다. 기존 Kenney Tiny Town(CC0) PNG 1개·5,042바이트를 실내 화분과 외부 지면에 재사용한다. 새 이미지·패키지·임시 파일은 없다. [에셋 활용 문서](cell-city-assets.md)를 함께 갱신한다.

검증 범위는 모든 부서·인수인계·휴식·개인 자리 도달, 충돌, 8명 동선, 저장 이전, 손과 바닥 상자를 포함한 물자 총량, 하루 전체의 교대·점심·대화·점검·정리, 사건 자동 해결, 플레이어의 먼저 줍기와 직접 배달, 휴식·꾸미기, 오프라인 캐시다. Work 설정에서 로컬 브라우저 사용이 꺼져 있어 실제 화면·계산된 스타일 검증은 미수행이다.
