기존 Canvas 형태 그림과 WebAudio 합성 방식을 확장했다. 저장소의 Play CC0 음악 목록도 검토했으며, 짧은 무기별 타격음은 샘플 다운로드 없이 합성한다. 신규 이미지·라이브러리 의존성은 없다.

## 검증

- 핵심 테스트 22개: 강화 확정·중복 적용 방지, 분기 배타성, 실제 수치와 카드 일치, NOVA/ARC 시점, 보호 시간, 화면 경계 생성, 적 분리·정리, 공격 패턴, 우선 표적, 장소, 기록 마이그레이션.
- `node scripts/benchmark-survival.mjs --profile --output=docs/survival-balance.json`
- 전략 실험은 실제 체력·성장 규칙을 사용한다. 화면 조건 2개 × 시드 3개 × 전략 4개 = 24회. 조작 정책은 고정된 자동 플레이어이므로 사람의 승률을 뜻하지 않는다.
- 최종 측정: 도주 0/6, 검체 추적 6/6, 펄스 집중 6/6, 다무기 6/6 성공. 첫 레벨업 중앙값은 검체 추적 1.883초, 도주 22.483초.
- 별도 용량 실험은 180개 적을 유지하기 위해 적 체력과 플레이어 보호를 높인다. 해당 값은 밸런스 비교에 포함하지 않는다. 엔진 tick p95 0.829ms, 최대 2.153ms.
- 프로파일에서 적 분리의 비중이 가장 높았지만 현재 상한에서 처리 예산에 여유가 있어 별도 공간 인덱스나 새 엔진을 추가하지 않았다.
- Node 엔진 처리만 측정했다. 실제 모바일의 Canvas 렌더링 FPS·터치 감각·소리 청감은 사용자 플레이 확인 범위다.
- 전체 저장소 테스트와 빌드는 GitHub Pages 배포 파이프라인에서 수행한다.
