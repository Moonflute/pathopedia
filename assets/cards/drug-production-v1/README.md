# 약제 카드 삽화

현재 약제 DB의 80종을 모두 같은 투명 배경 2D 그림체로 연결한다. 최초 제작에서 승인 시안 8종을 재사용했고, 항기생충·항원충 관련 19종은 2026-10-17 기준으로 새 도구 형태와 문양을 적용했다. 병원체·질환 카드와 같은 그림 보기 설정을 따른다.

## 형태와 색

- 페니실린: 단검. 세팔로스포린: 장검과 큰 로마 숫자 세대 표식. 모노박탐: 단도.
- 퀴놀론: 도끼. 카바페넴: 미사일. Aminoglycoside: 폭탄. 마크로라이드: 창.
- Vancomycin·Teicoplanin·Linezolid·Daptomycin: 대검.
- 테트라사이클린·글리실사이클린·린코사마이드: 해머.
- 항결핵제 4종: 같은 검의 서로 다른 네 조각.
- Metronidazole: 칼과 파리채. TMP–SMX·Fidaxomicin: 유리병.
- 항진균제: 스프레이. 항기생충제: 원충은 네모 파리채, 연충은 잠자리채, 외부기생충은 집게. 항바이러스제: 주사기, 비슷한 작용 대상끼리 형태를 공유.
- 그람양성 보라, 그람음성 분홍, 혐기성 회색, 비정형 빨강·흰색. 녹농균 표식은 작은 초록색 키링 장식.

도구의 끝은 왼쪽 위, 손잡이와 주사기 밀대는 오른쪽 아래로 향한다. 얇은 갈색 선, 평면 채색, 한두 단계의 명암을 사용한다. 주변 반짝임·입자·광채·흐림 효과 없이 실제 알파 투명 배경으로 만든다. 약제별 최종 형태·팔레트·참고 자료와 프롬프트는 jobs.json에 보존한다.

## 파일과 재사용

- jobs.json: 80종별 원본·웹 파일 경로, 프롬프트, 생성·수정 이력, 투명도 정보.
- prompts.md: 최종 프롬프트를 한 문서로 모은 기록.
- asset-integrity.json: 웹 변환 때 확인한 수량·크기·알파 채널과 원본/배포 용량.
- ../illustrations-v1/drugs/*.webp: 앱이 사용하는 무손실 WebP. 원본 PNG와 같은 크기 및 투명도를 유지한다.
- scripts/seed-drug-art.mjs: DB와 확정 디자인으로 작업 목록을 만들며 이미 생성된 항목을 보존한다. 로컬 승인 시안이 없어도 기존 제작 기록을 사용할 수 있다.
- scripts/save-card-art.mjs: 원본을 보존하여 복사하고, 병원체·질환·약제 그림 목록을 함께 갱신한다.
- scripts/prepare-card-art-web.mjs --drugs: 원본을 무손실 WebP로 형식 변환하고 앱 목록을 갱신한다. Sharp가 외부 런타임에 있으면 --module-dir로 지정한다.
- orchestration.js: Codex의 functions.exec 환경에서 기본 이미지 생성 도구를 호출하는 작업 함수. 일반 Node 실행용이 아니다.

현재 최종 PNG는 로컬에 보존한다. 교체된 항기생충제 구버전 이미지는 사용자의 명시적인 정리 요청에 따라 삭제하며, 파일 목록은 [정리 기록](../parasite-production-v2/cleanup.json)에 남긴다. 배포에는 목록에서 참조한 최종 WebP만 넣으며, 이미지 파일을 설치 시 한꺼번에 받지 않고 카드가 보일 때 불러온다.

항기생충제의 세부 도구·숙주 및 매개체 문양 기준은 [개정 제작 기록](../parasite-production-v2/README.md)을 따른다.
